# Database Design and SQL Labs

Учебный репозиторий с лабораторными работами по дисциплине «Основы реляционных баз данных».

**Технологии:** PostgreSQL 18.x, SQL.

## Цель проекта

Получение практических навыков проектирования реляционных баз данных, разработки их структуры, управления правами доступа и манипулирования данными с использованием SQL.

## Полученные навыки

- **Проектирование БД:** Создание структуры таблиц, определение типов данных (`numeric`, `character varying`, `date`, `smallint`) и ограничений целостности.
- **Обеспечение целостности:** Использование первичных ключей (`PRIMARY KEY`), внешних ключей (`FOREIGN KEY`) и проверок (`CHECK`).
- **Администрирование и безопасность:** Создание ролей (`ROLE`), управление привилегиями (`GRANT`, `REVOKE`), ограничение прав доступа на уровне таблиц (DCL).
- **Манипулирование данными (DML):** Написание запросов на выборку (`SELECT`), добавление, обновление (`UPDATE`) и удаление (`DELETE`) записей.
- **DDL-операции:** Модификация существующей структуры таблиц на лету с помощью `ALTER TABLE`.

## Реализованные базы данных

В рамках лабораторных работ были спроектированы и реализованы две предметные области:

### 1. Система учета сотрудников и истории должностей (Human Resources)
База данных предназначена для ведения кадрового учета компании.
*   **Таблица `employees`:** Содержит личные данные сотрудников (ФИО, дата рождения, пол, текущая должность, ставка заработной платы, адрес). Реализованы жесткие проверки ограничений (например, допустимая ставка `WageRate` от 0.1 до 1.5).
*   **Таблица `job_history`:** Хранит архив перемещений по службе (дата начала/конца работы на должности, номер департамента от 1 до 30). Связана с таблицей сотрудников связью «один ко многим».
*   **Безопасность (Управление доступом):** Настроены роли для разграничения прав (например, редактор базы данных `bd_editor` с правами на запись и чтение, а также пользователи с ограничениями `user_readonly` или `test2`).

### 2. Музыкальный каталог (Music Media Database)
База данных для каталогизации музыкальных альбомов, исполнителей и статистики продаж.
*   **Таблица `artists`:** Данные об исполнителях (название, страна, год основания).
*   **Таблица `albums`:** Информация о релизах (название, год выпуска, количество треков).
*   **Таблица `music_tracks`:** Каталог песен, связанных с конкретным исполнителем и альбомом.
*   **Таблица `disc`:** Коммерческие метрики физических или цифровых копий альбомов (стоимость, количество проданных копий).

## Структура репозитория

Каждая лабораторная работа размещена в отдельной директории.

В директориях могут находиться:
- `report.pdf` — отчёт о выполнении лабораторной работы;
- `file-nameschema.sql` — SQL-скрипт создания структуры базы данных и таблиц;
- `filename-queries.sql` — история реализованных SQL-запросов, скрипты тестирования ролей и манипуляции данными;
